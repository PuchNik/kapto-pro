# Капто Александр Александрович

Многостраничный сайт, созданный на основе https://www.kapto.pro/.

## Запуск

Дважды нажмите `start.cmd`. Откройте http://127.0.0.1:3000/.
В Cursor можно также выполнить `npm run dev`, если Node.js и npm добавлены в PATH.
Текущий проект использует уже установленные зависимости и Node.js из локального окружения Codex, если системный Node.js отсутствует.

## Структура

- `app/` — страницы, общая навигация, адаптивные стили.
- `content/pages.json` — исходные тексты и HTML-контент, распределённые по 47 внутренним страницам.
- `content/routes.json` — карта старых адресов и новых маршрутов; старые HTML-адреса перенаправляются автоматически.
- `public/original/` — оригинальные изображения и документы. Калькулятор сохранён с исходным JavaScript.
- `migration-report.json` — результат автоматической сверки переноса.

Главная плюс 47 внутренних страниц. Разделы: О докторе (биография, компетенции, образование, карьера, практика, преподавание, общества, награды); Наука (разработки и достижения); Публикации; Лекции; Проекты (библиотека, расчёты и анкеты); Контакты.

Тексты не перефразировались. Названия разделов и навигационные подписи обновлены. Сохранены исходные изображения. Удалено устаревшее форматирование Word/HTML и код счётчиков. Внешние адреса оставлены исходными.

В исходнике есть сломанная ссылка `https://www.kapto.pro/content/androweb.ru` (404). Она сохранена с исходным назначением. Страницы kapto.ru считаются внешними, как и другие сторонние домены.

Сайт разработан локально в указанной пользователем папке. На действующем kapto.pro ничего не изменялось. Отправка данных и медицинская логика не добавлялись. Исходный калькулятор сохранён без изменения формул.

## Проверки

`npm run build` — production-сборка; `npx tsc --noEmit` — типы.
Выполняется сверка наличия исходных текстовых фрагментов и локальных ресурсов, затем HTTP-проверка страниц.
Адаптивные режимы заданы для телефона, планшета и компьютера. Браузерное тестирование на реальных устройствах не проводилось.
